# iMybook

A reading-book desktop app built with Electron, HTML, CSS and JavaScript.
It uses the Open Library API (no API key needed)!

## Features
- Search books by title or author and view book details.
- Get book suggestions by genre, length and rating.
- Reading calculator (days needed to finish a book).
- READLIST: add, view, edit and delete books (saved in Local Storage).

## How to run
1. Install Node.js and Git
2. Clone this repository
3. Run `npm install`
4. Run `npm start`
